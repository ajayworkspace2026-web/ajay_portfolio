# Ajay Kumar Chinthapally — Developer Portfolio

A minimal-premium, cinematic sci-fi portfolio inspired by the mood of Avengers: Doomsday. This is an independent fan-inspired personal portfolio, not an official Marvel website. It does not use official logos or character artwork.

## Stack
- React + Vite
- Three.js via React Three Fiber / Drei
- Framer Motion
- Lucide icons
- Responsive custom CSS

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Before publishing
- Confirm project/demo URLs are correct.
- Verify certification and experience details against the latest resume/LinkedIn.
- Add a current resume PDF to `public/` before enabling a resume download.
- Run `npm run build` and test on mobile before deployment.

No API keys or backend required.
